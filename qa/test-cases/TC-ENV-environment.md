# TC-ENV — Environment Preflight

Scope: automated preflight gates that must pass before any manual test case in
this suite is attempted. Each row is a command to run and what "pass" means —
not a UI walkthrough. No signed-in user or seeded account is needed for any
case in this file. A red result on any P1 row here blocks the manual pass:
do not proceed to `TC-AUTH-*`, `TC-XCUT-*`, or any other file until every row
below is green. Commands and script names are taken verbatim from
`package.json`; server/port facts are taken from `vite.config.ts`,
`playwright.config.ts`, and `src/main.tsx`.
