# TC-RPT — Reports & Analytics Tab (Admin)

Covers spec 2.19 (Reports & Analytics Tab: 2.19.2 Report Dashboard, 2.19.2.1 Developers Report Tab,
2.19.2.2 Reviewers Report Tab, 2.19.2.3 Customers Report Tab, 2.19.3 Field Table) plus the "Report
Tab:" prose block in spec 1.5 (p.14-15), which is the only place the spec actually enumerates the
filters, three summary charts, key metrics cards, and sub-tab filters/metrics in prose (the numbered
2.19.x sections themselves contain only a screenshot placeholder and the top filter field table).

All cases sign in as Admin — Janith Hasthanayake (janith.hasthanayake@sebsaworld.com),
password `Sebsa@2026` — and navigate to `/crp/admin/reports`. Every figure is computed client-side in
`src/portals/code-review/features/reports/domain/reportMetrics.ts` over the full task/review set, so a
fresh reload is only needed when a case depends on a specific known seed state; otherwise any signed-in
session is fine since Reports reads live (session) data, not a snapshot.
