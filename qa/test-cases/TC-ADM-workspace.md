# TC-ADM — Admin Workspace

Covers spec 2.12 (Admin Workspace landing), 2.13 (Tasks Management Tab), 2.14/2.15 (User Management
Tab and its Add User dialog), 2.16/2.17 (Customers Management Tab and its Add Customer dialog), the
"Admin Workspace" prose block in spec 1.5 (p.12-13), and the Quality Checklist tab
(`/crp/admin/checklist`), which the spec does not describe at all (see sub-area below).

All cases sign in as an Admin-role user — Janith Hasthanayake (janith.hasthanayake@sebsaworld.com),
password `Sebsa@2026`, unless a case explicitly calls for a different account (e.g. the negative
developer-only guard test uses Dheliya Kankanamge). The Handovers tab (`/crp/admin/handovers`) is
covered by `TC-HAND-handovers.md`; this file only confirms the tab exists and links there. Because the
mock DB is in-memory and rebuilt on every reload, each case states whether it needs a fresh reload
(clean seed data) or must continue from a prior step without reloading.
