# Local-auth manual test list

Temporary feature: remove this file with `apps/web/src/features/local-auth`.

The screens are always on, against the NestJS API (there is no mock). Setup is in
`docs/email-notifications.md`.

Links look like `{APP_BASE_URL}/set-password#token=...`. Getting them:

- **`EMAIL_ENABLED=true`** (Brevo): the email arrives in the user's inbox. Check spam too.
- **`EMAIL_ENABLED=false`**: the API log prints each email as `[dev outbox] <subject> -> <email>`
  followed by the text, including the link.

Get an expired link by setting `password_links.expires_at` into the past on the e2e database (never on
Neon), or a low `INVITE_TTL_HOURS`. Get a used link by saving a password, and an unknown one by editing a
character.
