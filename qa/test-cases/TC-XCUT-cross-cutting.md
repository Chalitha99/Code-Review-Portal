# TC-XCUT — Cross-Cutting Concerns

Scope: concerns that apply across the whole Code Review Portal rather than to
one spec section — keyboard access, focus visibility, screen-reader names on
icon-only controls, the accessible presentation of charts, small-viewport
layout, mock-API and route-level error recovery, the 404 page, and the two
"coming soon" portal placeholders. Spec ref is `—` throughout unless a
specific clause applies, per the shared convention. Primary user: Janith
Hasthanayake (janith.hasthanayake@sebsaworld.com — Developer, Reviewer,
Admin), so every workspace is reachable in one session without a role switch.
