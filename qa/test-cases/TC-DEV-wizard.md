# TC-DEV-wizard — New Task Creation Wizard

Covers spec 2.5 (New Task Creation Page, field table 2.5.3, RMB 2.5.3.1, FL 2.5-01, FL 2.5-02, FL 2.2-03), as actually implemented in `src/portals/code-review/features/tasks/routes/NewTaskWizard.tsx`, `WizardDetailsStep.tsx`, and `hooks/useTaskDraft.ts`.

**Structural gap vs. spec (read before writing further cases against this app):** the spec describes a single "New Task Creation Page" with a "Complete Checklist" button that routes to a separate "Developer Quality Checklist Page". The implemented app instead uses one 3-step URL wizard at `/crp/developer/tasks/new/:step`, with steps `details` (spec's Task Details), `checklist` (spec's Developer Quality Checklist), and `review` (not in spec — a "Review & Submit" summary step). There is no button literally named "Complete Checklist"; the equivalent control is "Next: Quality Checklist". This is flagged for the gap register, not treated as a defect in the cases below — every case names the control by its real accessible text (`tasks.json` `wizard.*`).
