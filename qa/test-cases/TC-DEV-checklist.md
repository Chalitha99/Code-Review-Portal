# TC-DEV-checklist — Developer Quality Checklist (wizard step 2)

Covers spec 2.6 (Developer Quality Checklist Page — Table 1, Table 2, RMB 2.6.3.1, FL 2.6-01, FL 2.6-02, FL 2.6-03), implemented as the "Quality Checklist" step of the task wizard (`WizardChecklistStep.tsx`, `domain/checklistRules.ts`) rather than as a separate page — see the structural gap note in `TC-DEV-wizard.md`. Task types and questions are read from `src/mocks/data/taskTypes.json` and `src/mocks/data/checklistTemplate.json`.

Primary user: **Udari Heshani** (udari.heshani@sebsaworld.com), Developer role, password `Sebsa@2026`. Cases build on each other within one wizard session; state does not need a reload between them unless noted.

**Task Types confirmed in seed data (`taskTypes.json`):** Customization, Configuration, Lobby, Quick Report, Upgrade Service.

**Gap confirmed:** there is no "Save Checklist" button in this app — the equivalent action is "Next: Review & Submit" on the checklist step, which both saves and advances. Likewise "Cancel" for the wizard as a whole is the bottom action bar's "Cancel" (see TC-DEV-WIZ-011) rather than a checklist-specific Cancel.
